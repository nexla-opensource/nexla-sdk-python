### AsyncHttpxClient

Defined in `nexla_sdk/aio/http_client.py:84`

Async HTTP client with the SDK retry rules (spec sections 3 and 4).

- Connect failures: every method.
- Read timeouts and resets after send, and 502/503/504: idempotent methods only.
- 429: every method. The wait comes from the body ``error.retry_after``,
  then ``Retry-After``. A wait over 60 s is not retried.

Retries use ``asyncio.sleep``. The request body is resent unchanged.

### AsyncNexlaClient

Defined in `nexla_sdk/aio/client.py:101`

Async client for the Nexla API.

Use it as an async context manager, or call ``aclose()`` when finished.
Authentication modes are the same as NexlaClient: service key, API key,
email and password, or access token.

Examples:
    async with AsyncNexlaClient(service_key="your-service-key") as client:
        sources = await client.sources.list()
        async for source in client.sources.paginate(per_page=50).iter_items():
            print(source.name)

Note:
    Resource methods are coroutines. ``paginate()`` returns an AsyncPaginator
    that you iterate with ``async for``.

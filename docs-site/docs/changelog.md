The changelog is kept in [CHANGELOG.md](https://github.com/nexla-opensource/nexla-sdk-python/blob/main/CHANGELOG.md) at the repository root. It lists the unreleased changes and every release from 0.1.3 onward.

Use `pip install nexla-sdk==<version>` to pin a release. Run `git log <old>..<new>` to see the full diff between two tags.
